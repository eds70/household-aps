# Миграции БД

Каталог содержит **историю изменений схемы БД** после релиза v1.2.0.

## Файлы

| Файл | Что содержит | Итерации |
|------|--------------|----------|
| `add_history_0_2.sql` | Склейка add_01..add_05: organization_settings, feature-флаги, цепочки рабочих центров, equipment.code, 28 партий, включение материальных ограничений | 0–2 |
| `add_06.sql` (планируется) | Сменное планирование: таблица shift, поля actual_*, shift_id | 3 |
| `add_07.sql` (планируется) | Перепланирование: is_pinned, reschedule_log | 4 |

## Когда применять

**`init_schema.sql` (v1.3.0) — для пустой БД.** Создаёт актуальную схему.

**`add_history_0_2.sql` — для апгрейда существующей БД** (v1.2.0 → v1.3.0). Все операции идемпотентны, повторное применение безопасно.

## Как применять

```powershell
Get-Content -Raw backend\migrations\add_history_0_2.sql | docker exec -i aps_postgres psql -U aps -d household
