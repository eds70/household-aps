Проанализируй файлы. (project_dump.txt, README.md, ТЗ.txt) 
Определи в какой стадии находится сейчас проект. Предложи план дальнейшей работы.
Прими следующие правила для своей работы:
- листинг всех исправленных файлов ВСЕГДА! выводить полностью
- после вывода каждого измененного файла ждать команды, чтобы вывести следующий файл
- комментарии по изменениям пиши сжато
- все команды общения с БД оборачивать командам работы с docker, например:
docker exec -i aps_postgres psql -U aps -d household -c "SELECT type, capacity FROM resource_pool ORDER BY type;"
