# 🏭 APS Production Scheduler

**Система автоматического планирования производства на базе OR-Tools CP-SAT**

## 📋 Описание

APS (Advanced Planning and Scheduling) — полнофункциональная система оптимального планирования производства для химической промышленности (бытовая химия). Строит расписание загрузки оборудования с учетом:

- Технологических карт и строгой последовательности операций
- Ограничений оборудования (бойлеры, зоны охлаждения, операторы, вместимость)
- Матрицы замывки (setup times) между разными партиями (30/90 минут)
- Календаря простоев (выходные, плановые ремонты, аварии)
- Ресурсных ограничений и доступности материалов
- Версионирования планов (снапшоты справочников на момент планирования)

## 🎯 Ключевые возможности

- ✅ Динамический расчет длительностей операций (вязкость, объем, тип мешалки)
- ✅ Оптимизация через OR-Tools CP-SAT (минимизация makespan)
- ✅ Учет матрицы замывки между партиями (30/90 минут)
- ✅ Календарь простоев (выходные, плановые ремонты, аварии)
- ✅ Версионирование планов с сохранением снапшотов справочников
- ✅ Управление материалами, рецептурами и производственными заказами
- ✅ Автоматическое разбиение заказов на партии по объему реактора
- ✅ REST API на FastAPI с Swagger UI
- ✅ Экспорт плана в Excel с диаграммой Ганта
- ✅ Интерактивная визуализация диаграммы Ганта (vis-timeline)
- ✅ Read-only режим при просмотре исторических версий планов

- Python 3.12+

### Шаг 1: Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd household-aps
```

### Шаг 2: Запуск базы данных (PostgreSQL в Docker)

```bash
docker run --name aps-postgres \
  -e POSTGRES_USER=aps \
  -e POSTGRES_PASSWORD=aps_secret \
  -e POSTGRES_DB=household \
  -p 5432:5432 \
  -d postgres:16
```

**Проверка запуска контейнера:**

```bash
docker ps
```

## 📚 Документация API

После запуска backend откройте **http://localhost:8000/docs** для интерактивной документации Swagger UI.

### Основные группы эндпоинтов

| Группа | Префикс | Описание |
|--------|---------|----------|
| Оборудование | `/api/v1/equipment` | CRUD оборудования с поддержкой версионирования |
| Продукты | `/api/v1/products` | Справочник ПФ и ГП с поддержкой версионирования |
| Материалы | `/api/v1/materials` | Сырье, упаковка, этикетки + управление остатками |
| Рецептуры | `/api/v1/recipes` | Состав ПФ с компонентами |
| Операции | `/api/v1/operations` | Технологические карты и этапы производства |
| Заказы | `/api/v1/orders` | Производственные заказы и партии + авто-разбиение |
| Планирование | `/api/v1/schedule` | Построение и версии планов (`/build`, `/save`, `/versions`) |
| Гант | `/api/v1/gantt` | Данные для диаграммы и экспорт в Excel |
| Календарь | `/api/v1/calendar` | Простой оборудования с поддержкой версионирования |

### Примеры запросов

**Построение плана:**

```bash
POST /api/v1/schedule/build
{
  "horizon_hours": 2160,
  "timeout_seconds": 120
}
```

**Получение списка версий:**

```bash
GET /api/v1/schedule/versions
```

**Авто-разбиение заказа на партии:**

```bash
POST /api/v1/orders/{order_id}/auto-split?equipment_id=<UUID>&max_fill_percent=0.70
```

**Получение оборудования с учетом версии плана:**

```bash
GET /api/v1/equipment?version_id=<UUID>
```

## 🧩 Основные сущности

### Оборудование
- **Реакторы** (REACTOR) — 4 шт с разным объемом и скоростью
- **Линии розлива** (FILLING_LINE) — 3 шт
- **Накопительные емкости** (TANK)
- **Бойлер** (BOILER)
- **Ручные станции** (MANUAL_STATION)

### Продукция
- **Полуфабрикаты (ПФ)**: Крем-мыло, Средство для мытья посуды, Антисептик
- **Готовая продукция (ГП)**: разлив в тару 1л, 5л, 10л

### Материалы
- **Сырье (RAW)**: вода, соль, отдушки, глицерин, спирт
- **Упаковка (PACKAGING)**: бутылки, канистры, крышки
- **Этикетки (LABEL)**

### Технологические карты
- 8-11 этапов на каждый ПФ
- Параллельные группы операций
- Формулы расчета длительностей

### Матрица замывки
- 30 мин — тот же ПФ
- 90 мин — другой ПФ
